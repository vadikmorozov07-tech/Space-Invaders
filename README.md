# Space-Invaders

Классическая аркадная игра **Space Invaders**, разработанная на C++ с использованием графической библиотеки SFML.

## Описание проекта

Игрок управляет космическим кораблём, перемещается по игровому полю и уничтожает волны противников.

В игре реализованы движение и стрельба игрока, движение формации противников, ответная стрельба врагов, система очков и жизней, а также меню паузы.

Для победы необходимо пройти 10 волн противников.

## Основные возможности

* управление космическим кораблём;
* стрельба игрока;
* движение формации противников;
* стрельба противников;
* 10 волн противников;
* система очков;
* система жизней;
* меню паузы;
* победа после прохождения 10-й волны;
* завершение игры после потери всех жизней;
* обработка столкновений игровых объектов;
* загрузка текстур и шрифтов из внешних ресурсов.

## Управление

| Клавиша | Действие                   |
| ------- | -------------------------- |
| `W`     | движение вверх             |
| `A`     | движение влево             |
| `S`     | движение вниз              |
| `D`     | движение вправо            |
| `Space` | выстрел                    |
| `Esc`   | открыть/закрыть меню паузы |

В меню паузы доступны две кнопки. Взаимодействие с кнопками осуществляется с помощью мыши.

## Игровая механика

* За уничтожение противника игрок получает очки.
* При попадании в игрока вражеским снарядом теряется жизнь.
* За каждого противника, достигшего нижней границы игрового поля, теряется жизнь.
* После потери всех жизней игра завершается.
* После уничтожения всех противников текущей волны начинается следующая волна.
* После прохождения 10-й волны игрок одерживает победу.

## Архитектура проекта

Проект разделён на несколько основных классов:

* `Game` — управление игровым процессом и взаимодействием игровых объектов;
* `Player` — управление игроком и его кораблём;
* `Enemy` — логика противников, их движение и стрельба;
* `Bullet` — создание и движение снарядов;
* `Menu` — меню паузы и обработка взаимодействия с его кнопками.

Для определения принадлежности снаряда используется перечисление `BulletOwner`, позволяющее различать снаряды игрока и противников.

## Сборка и запуск

Для сборки программы используется система **CMake**, а для управления внешними зависимостями — менеджер пакетов **vcpkg**. В проекте используется библиотека **SFML версии 3.0.2**.

Сборка программы выполняется в операционной системе **Windows** с использованием **Visual Studio 2026**. Основные параметры сборки задаются в файлах `CMakeLists.txt` и `CMakePresets.json`.

Для сборки и запуска программы необходимо открыть **PowerShell в корневой директории проекта** и выполнить следующие команды.

### 1. Конфигурация проекта

```powershell
cmake --preset windows
```

### 2. Сборка программы

```powershell
cmake --build --preset windows-debug
```

### 3. Запуск программы

```powershell
.\build\Debug\SpaceInvaders.exe
```
